# Contributing to Trezv777 Mobile Suite

## Как внести вклад

1. Форкните репозиторий
2. Создайте ветку для фичи (`git checkout -b feature/amazing-feature`)
3. Запустите анализ кода перед коммитом
4. Запушьте изменения и откройте Pull Request

## Требования к коду

- Используйте `flutter analyze` для проверки
- Следуйте Dart style guide
- Пишите тесты для новых функций
- Обновляйте документацию

## Запуск проверок

```bash
# Анализ кода
flutter analyze

# Тесты
flutter test

# Сборка
flutter build apk
```

## Code Style

- Используйте `dart format`
- Следуйте Effective Dart
- Используйте type hints
- Документируйте публичные методы
